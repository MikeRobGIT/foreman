# foreman 0.5.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fix the 15 findings of the 0.5.0 dry runs: batch state moves to disk (`scripts/batches.py`), hook piece 11 (`batch_state`) enforces the tables, TaskStop ids and releases at the tool call, the status band reads the batch files, and SKILL.md's spec phase follows. This is foreman 0.5.1.

**Architecture:**
- A new stdlib script, `scripts/batches.py`, keeps one JSON file per batch under `<state dir>/batches/<session>/state/` in every state dir, renders the W3.6 checkpoint table and the W6 report table, and stamps each render.
- `scripts/hooks.py` gains piece 11 (`batch_state`): a worker deny for `batches.py`, a checkpoint gate on `AskUserQuestion`, a report gate on `run-end`, a TaskStop guard, and a release check on `hooks.py release`. The gates read the transcript for the pasted table, from the end.
- Smaller changes back it: `review.sh` writes `<log>.entry`, `cfg.chain` takes `use_env`, a `SessionStart` hook exports `FOREMAN_SESSION`, the status mod reads `batches.py show --json`, the templates gain the open-question labels and a `forbid_trailers` default, and SKILL.md's W2–W6, Worker contract and Worker spec phase use all of it.

**Tech Stack:** Python 3 standard library, Bash 3.2 (macOS `/bin/bash`), Node 22 (`node --test`) for the status mod, Claude Code skill markdown and hooks.

**Spec:** `docs/superpowers/specs/2026-10-04-foreman-0.5.1-design.md` (revision 6) is the authority; read it with this plan.

**Base:** branch `feat/spec-phase-fixes` in `/Users/crisis/_workspace/foreman.wt/spec-phase`, at commit `24367e8` (foreman 0.5.0 plus the spec). Every path below is relative to that worktree. ## Global Constraints

- Python 3 standard library only; Bash runs on macOS `/bin/bash` 3.2 (no `declare -A`, `mapfile`, `timeout`).
- Tests use a temp `FOREMAN_HOME`, a temp `HOME` and temp repos: never `~/.claude/foreman`, `~/.claude/settings.json` or the shell profile. `Fx.env` drops `FOREMAN_CONFIG`, `FOREMAN_SESSION` and `CLAUDE_ENV_FILE` from the inherited environment.
- Commit messages: no `Co-Authored-By` and no "Generated with"; end each with the trailer `Claude-Session: https://claude.ai/code/session_01PvGpNYJt8BPj2jfGq1qPKz` (the user's rule).
- `batches.py` exit codes: 0 done, 1 refused with a one-line reason on stderr, 2 usage error. Every argument is one shell word with no quotes, spaces, `;` or `$`; free text goes through `note <file>`.
- State file location: `<state dir>/batches/<session>/state/<batch>.json`, in every `state.state_dirs(main)` entry; readers take the newest copy by mtime. Stamps: `<wave>.shown` and `report.shown` = `{at, id, text}`; deny counts `<wave>.denies` and `report.denies` = `{id, count}`.
- Status tokens: `spec`, `review`, `passed`, `released`, `pr`, `parked`. Reason tokens (with `status=parked` only): `open-question`, `no-pass`, `timed-out`, `spec-incomplete`, `bounces`, `review-failed`, `worker-stuck`, `not-released`, `scope-conflict`, `release-unrecorded`, `stopped-by-human`, `comment-failed`. Task kinds: `worker`, `timer`, `chain`, `reviewer`. Fall-through reasons: `error`, `quota`, `reads-repo`, `timeout`, `missing`.
- Table first line: `foreman checkpoint <wave> <id>` or `foreman report <session> <id>`, `<id>` = the first 8 hex digits of the SHA-1 of the rendered Markdown table. No cell depends on the clock.
- `<wave>` = a batch name minus its final letter. Workers are named `fw-<batch>`; replacements `fw-<batch>-2`, `fw-<batch>-3`, …
- Piece 11's id is `batch_state`. Every deny of duties 2–5 names `hooks_disabled: [batch_state]` and writes commands with the resolved script path (`HERE`), never `$FOREMAN`.
- Run scope: with a live run marker, the tables, the gates, `show` and the status band see only batches whose name time (`batch_time`) is at or after the marker's `started`, floored to the minute; with none, the whole session.
- Version `0.5.1` in `.claude-plugin/plugin.json` and `.claude-plugin/marketplace.json`.
- Run the suite with `bash tests/run.sh 2>&1 | grep -E '^(FAIL|passed)'` (about 4 minutes: `test_hooks.py` alone takes 3). Run one class of `test_hooks.py` with `cd tests && python3 -m unittest test_hooks.<Class>`.
- Run the suite in the foreground, never as a `&` job of a script: non-interactive bash starts a `&` job with SIGINT ignored, and `ReceiptMintTest.test_a_killed_gate_removes_its_untracked_snapshot` (unchanged since 0.5.0) then fails with exit 0 instead of 130.

## Rulings on the spec

The spec leaves these open; the plan decides them, and the code and tests follow:
- **SHA comparison is by prefix.** `release_sha`/`reviewed_sha` and `hooks.py release <sha>` match when one is a prefix of the other (both are 7 to 40 hex digits, the shape `hooks.py` already accepts). The orchestrator may copy a short SHA from one place and a full one from another.
- **`passed` and `ended` stamps are appended on a status change only**, so a repeated `set status=passed` doesn't move the "latest pass" that the release check compares the checkpoint stamp against.
- **`ended` closes an open worker-time interval**, so a parked batch's clock stops at the park.
- **An undated batch name is outside every run's scope** while a run marker is live (its `batch_time` is 0). W2's names are always dated.
- **The hook writes deny counts to `repo.dirs[0]` only** (the hooks are their only reader and writer), and doesn't take the lock.
- **`degraded` is empty before any round** (rendered `—`), except that a chain with no spec-eligible entry is always `yes`.
- **P3 = next-message with `updatedInput no` keeps duty 2's deny text** ("paste the output of `…table checkpoint <wave>` as text before asking") rather than the spec's "put the checkpoint table in your text before asking": the two say the same thing, and Task 12 Step 7 has W3.6 paste the table in a message of its own and make one more call before asking, so the transcript holds it when the hook reads it; the third-deny escape still applies. With `updatedInput ask`, Task 5 Step 6's `'allow'` is written `'ask'` (the step says so).
- **P3's duty-3 fallback needs no code:** the transcript check already reads every assistant message after the stamp, so a paste in an earlier message passes `run-end`. Only the SKILL text changes (Task 12's P3 step).

## Review Focus

1. **A `|` inside a Minor finding** (e.g. "split `a | b`"): the table escapes it as `\|`, and the pasted text, escape included, still satisfies the gate. Test: Task 5 (`test_a_pipe_in_a_minor_finding_and_a_fenced_paste_round_trip`).
2. **The table pasted inside a code fence** (` ``` ` lines around it): the fence lines are extra, every table line is still a line of the text, so the question passes. Test: Task 5 (same test).
3. **Two waves at the checkpoint at once** (a `/loop` tick or a slow wave): every question needs both waves' tables, and the deny names the missing one. Test: Task 5 (`test_two_waves_at_the_checkpoint_need_both_tables`).
4. **A short SHA in one place and the full SHA in another** (`hooks.py release <b> c0ffee12…` against a full `reviewed_sha`): accepted as the same commit; a different SHA is refused. Tests: Task 2 (`test_a_release_set_needs_the_reviewed_sha`), Task 6 (`test_auto_merge_releases_only_a_passed_batch_at_its_reviewed_sha`).
5. **`batches.py` run from a worktree** (the orchestrator `cd`s into a batch's worktree): the state lands in the main checkout's state dir, where the hooks and the other calls read it. Test: Task 2 (`test_a_worktree_cwd_writes_the_main_checkouts_state`).

**Interfaces:**
- Consumes: the base commit `24367e8`; `rtk` and `jq` on PATH (P2); `tmux`; `claude` signed in.
- Produces: the `## Probe results` section at the end of this plan (Step 6), committed. Every later task reads its probe outcome there, never from a scratch file. It holds one line per probe, with exactly one of these outcomes, which pick the conditional steps:
  - `P1 = works` or `P1 = fails` (Task 4 Step 7 applies on `fails`);
  - `P2 = wrapper`, `P2 = absolute` or `P2 = neither` (Tasks 10 and 13 apply the matching steps), plus P2's form-by-hook table;
  - `P3 = same-message` or `P3 = next-message`, and with `next-message` also `P3 = updatedInput allow`, `P3 = updatedInput ask` or `P3 = updatedInput no` (Tasks 5 and 12 apply the matching steps; a step marked `(only if P3 = updatedInput)` applies on `allow` or `ask`);
  - `P4 = no-pty` or `P4 = pty` (Task 11 Step 6 applies on `pty`), plus which TaskStop forms worked.

The probes drive Claude Code in tmux, and every probe session is isolated from the user's own setup:
- **`--setting-sources project,local`**: only the settings the probe writes apply. The user's `~/.claude/settings.json` stays out, with its hooks (a global RTK hook among them), its `defaultMode` (`auto` approves the very prompts P2 has to see) and its plugins (an installed foreman would add its own hooks).
- **`--permission-mode manual`**: every prompt is shown, none is approved for you. `manual` is this CLI's name for the prompting mode: `claude --help` lists `acceptEdits`, `auto`, `bypassPermissions`, `manual`, `dontAsk` and `plan`. A CLI that lists `default` instead takes `default`.
- **The trust dialog.** A new directory opens on the workspace-trust dialog, and the project-local hooks under test load only once it is accepted. The `start` helper accepts it (Enter on its first option, `Yes, proceed`) before anything is typed.

Shell variables don't carry between Bash calls, and a foreground `sleep` is refused in a Claude Code Bash call. So Step 1 writes two helpers to `/tmp/fm-probe-lib.sh`, every later block that needs them sources it, and every block that waits runs with `run_in_background` (go on at its notification):
- `waitfor <session> <regex> <seconds>` polls the pane until the regex shows or the time is up.
- `start <session> <dir> [VAR=value …]` opens the session, accepts the trust dialog, and returns once the input box shows (a `❯` with no `trust` on screen). After 60 seconds without it, it returns 1: attach (`tmux attach -t <session>`, detach with `C-b d`) and look before going on.

```bash
# waitfor <session> <regex> <seconds>: poll the pane until the regex shows or the time is up
waitfor() { local s=$1 re=$2 n=$3; until tmux capture-pane -p -t "$s" | grep -qE "$re" || [ "$n" -le 0 ]; do sleep 1; n=$((n - 1)); done; }
# start <session> <dir> [VAR=value ...]: a session with only the probe's own settings, past the trust dialog
start() {
  local s=$1 d=$2 n=60 pane
  shift 2
  tmux new-session -d -s "$s" -c "$d" "env $* claude --permission-mode manual --setting-sources project,local"
  while [ "$n" -gt 0 ]; do
    pane=$(tmux capture-pane -p -t "$s")
    if printf '%s' "$pane" | grep -qi 'trust'; then
      tmux send-keys -t "$s" Enter
    elif printf '%s' "$pane" | grep -q '❯'; then
      return 0
    fi
    sleep 1
    n=$((n - 1))
  done
  return 1
}
EOF
bash -n /tmp/fm-probe-lib.sh && echo LIB-OK
```

Expected: `LIB-OK`.

- [ ] **Step 4: P3 — is the text written before a tool call already in `transcript_path` when the hook fires, and does `updatedInput` reach the dialog?**

````python
#!/usr/bin/env python3
"""foreman's batch state for the parallel spec phase: one JSON file per batch, written only by the orchestrator.

  batches.py set <batch> key=value...                  create the file on first use; set the keys
  batches.py note <batch> minors|questions|park_note <file>   the field becomes the file's non-empty lines
  batches.py bump <batch> pr_rounds|bounces            add one
  batches.py stamp <batch> sent|comment_sent|spec_ready|stopped
  batches.py task <batch> add <kind> <id> | verdict <id> | done <id>
  batches.py add-round <batch> r=<n> sha=<sha> entry=<n> [fallthrough=<adapter:why,...>] explore=<pass|revise|none>
                       crit=<n> imp=<n> minor=<n>
  batches.py show [<batch>] [--json]
Every command takes `--session <id>`. Exit 0 = done, 1 = refused (one line on stderr), 2 = usage.

Files: <state dir>/batches/<session>/state/<batch>.json in every state.state_dirs(main) entry (hooks.py forget
never reaches them); reads take the newest copy. Session: --session, else $FOREMAN_SESSION, else the most
recently touched live run marker, else `nosession`. Run scope: with a live run marker, `show` and the tables see
only batches named at or after the marker's `started` minute.
"""
import contextlib
import fcntl
import glob
import json
import os
import re
import sys
import tempfile
import time

HERE = os.path.dirname(os.path.abspath(__file__))
sys.path.insert(0, HERE)
import cfg  # noqa: E402
import state  # noqa: E402

RUN_TTL = 48 * 3600
NAME = re.compile(r'^[A-Za-z0-9_-]+$')
SHA = re.compile(r'^[0-9a-f]{7,40}$')
TOKEN = re.compile(r'^[A-Za-z0-9_.,/:@+-]+$')
TASK_ID = re.compile(r'^[A-Za-z0-9_.:@-]+$')
INT = re.compile(r'^(0|[1-9][0-9]*)$')
STATUSES = ('spec', 'review', 'passed', 'released', 'pr', 'parked')
REASONS = {
    'open-question': 'open question', 'no-pass': 'no pass in {n} rounds', 'timed-out': 'spec phase timed out',
    'spec-incomplete': 'spec incomplete', 'bounces': 'spec incomplete after 2 bounces',
    'review-failed': 'review could not run', 'worker-stuck': 'worker stuck',
    'not-released': 'not released by the human', 'scope-conflict': 'scope conflict',
    'release-unrecorded': 'release could not be recorded', 'stopped-by-human': 'stopped by the human',
    'comment-failed': 'comment round failed',
}
FIELDS = {
    'status': lambda v: v in STATUSES,
    'reason': lambda v: v in REASONS,
    'rows': TOKEN.match, 'owned': TOKEN.match, 'branch': TOKEN.match, 'spec': TOKEN.match,
    'worktree': lambda v: TOKEN.match(v) and v.startswith('/'),
    'fork_base': SHA.match, 'sha': SHA.match, 'reviewed_sha': SHA.match, 'released_sha': SHA.match,
    'verified_sha': SHA.match,
    'pr': lambda v: INT.match(v) and v != '0',
    'reviewer_model': TOKEN.match,
}
COUNTERS = ('pr_rounds', 'bounces')
TEXTS = ('minors', 'questions', 'park_note')
STAMPS = ('sent', 'comment_sent', 'spec_ready', 'stopped')
KINDS = ('worker', 'timer', 'chain', 'reviewer')
WHYS = ('error', 'quota', 'reads-repo', 'timeout', 'missing')


class Fail(Exception):
    """A refusal: exit 1 with the message on stderr."""


class Usage(Exception):
    """A malformed command: exit 2."""


def batch_time(batch):
    """Epoch seconds of a `YYYYMMDD-HHMM-...` batch name (local time), or 0 for an undated name (hooks.batch_time)."""
    m = re.match(r'^(\d{8}-\d{4})-', batch)
    try:
        return time.mktime(time.strptime(m.group(1), '%Y%m%d-%H%M')) if m else 0
    except ValueError:
        return 0


def same_sha(a, b):
    """Two SHAs name the same commit: equal, or one abbreviates the other (both at least 7 hex digits)."""
    return bool(a and b and (a.startswith(b) or b.startswith(a)))


def rm(path):
    try:
        os.remove(path)
    except OSError:
        pass


class Store:
    """One session's batch files across the repo's state dirs."""

    def __init__(self, main, dirs, sid):
        self.main, self.dirs, self.sid = main, dirs, sid

    def path(self, d, name):
        return os.path.join(d, 'batches', self.sid, 'state', name)

    def read(self, name):
        """The newest copy of `name` across the dirs, or None. A copy that isn't JSON is refused, untouched."""
        best = None
        for d in self.dirs:
            p = self.path(d, name)
            if os.path.isfile(p):
                t = os.stat(p).st_mtime_ns
                if best is None or t > best[0]:
                    best = (t, p)
        if best is None:
            return None
        try:
            with open(best[1], encoding='utf-8') as f:
                return json.load(f)
        except ValueError:
            raise Fail(f'corrupt batch state: {best[1]}')

    def write(self, name, data):
        """Every dir's temp file first, then each moved into place. A dir that fails after the first was replaced
        is named on stderr and the call still succeeds, so a retry never applies a change twice."""
        text = json.dumps(data, indent=1, sort_keys=True)
        temps = []
        try:
            for d in self.dirs:
                p = self.path(d, name)
                fd, tmp = tempfile.mkstemp(dir=state.ensure(os.path.dirname(p)), suffix='.tmp')
                temps.append((tmp, p))
                with os.fdopen(fd, 'w') as f:
                    f.write(text)
        except OSError as e:
            for tmp, _ in temps:
                rm(tmp)
            raise Fail(f'could not write batch state: {e}')
        for i, (tmp, p) in enumerate(temps):
            try:
                os.replace(tmp, p)
            except OSError as e:
                for t, _ in temps[i:]:
                    rm(t)
                if i == 0:
                    raise Fail(f'could not write batch state: {e}')
                print(f'batches.py: {name} not written in {os.path.dirname(p)} ({e.strerror}); readers use the '
                      'newest copy', file=sys.stderr)
                return

    @contextlib.contextmanager
    def lock(self):
        d = state.ensure(os.path.join(self.dirs[0], 'batches', self.sid, 'state'))
        with open(os.path.join(d, '.lock'), 'a') as f:
            fcntl.flock(f, fcntl.LOCK_EX)
            yield

    def started(self):
        """The live run marker's `started` for this session, floored to the minute, or None."""
        best = None
        for d in self.dirs:
            m = state.read_json(os.path.join(d, 'runs', self.sid + '.json'))
            if isinstance(m, dict) and time.time() - float(m.get('touched', 0)) < RUN_TTL:
                if best is None or float(m.get('touched', 0)) > float(best.get('touched', 0)):
                    best = m
        if best is None:
            return None
        s = float(best.get('started', 0))
        return s - s % 60

    def batches(self):
        """Every batch of the current run (the whole session with no live run marker), by name."""
        names = set()
        for d in self.dirs:
            for p in glob.glob(os.path.join(glob.escape(self.path(d, '')), '*.json')):
                names.add(os.path.basename(p)[:-len('.json')])
        since = self.started()
        out = []
        for n in sorted(names):
            if NAME.match(n) and (since is None or batch_time(n) >= since):
                b = self.read(n + '.json')
                if isinstance(b, dict):
                    out.append(b)
        return out


def session_id(dirs, given):
    sid = given or os.environ.get('FOREMAN_SESSION')
    if not sid:
        live = []
        for d in dirs:
            for p in glob.glob(os.path.join(glob.escape(d), 'runs', '*.json')):
                m = state.read_json(p)
                if isinstance(m, dict) and time.time() - float(m.get('touched', 0)) < RUN_TTL:
                    live.append((float(m.get('touched', 0)), os.path.basename(p)[:-len('.json')]))
        if not live:
            return 'nosession'
        live.sort(reverse=True)
        sid = live[0][1]
        if len({s for _, s in live}) > 1:
            print(f'batches.py: {len({s for _, s in live})} live runs; using session {sid}, the most recently touched '
                  '(pass --session <id> to pick another)', file=sys.stderr)
    if not NAME.match(sid):
        raise Usage(f'bad session id: {sid}')
    return sid


def open_store(given):
    main = state.main_checkout(os.getcwd())
    if not main or not cfg.config_path(main, use_env=False):
        raise Fail('no state dir: run batches.py inside a repo with a foreman config')
    dirs = state.state_dirs(main)
    return Store(main, dirs, session_id(dirs, given))


def new_batch(name):
    return {'batch': name, 'pr_rounds': 0, 'bounces': 0, 'stamps': [], 'tasks': [], 'rounds': []}


def pairs(args, allowed):
    out = {}
    for a in args:
        k, eq, v = a.partition('=')
        if not eq or k not in allowed:
            raise Fail(f'unknown key: {k}')
        if not v or not allowed[k](v):
            raise Fail(f'bad value for {k}: {v}')
        out[k] = v
    if not out:
        raise Usage('no key=value given')
    return out


def stamp(b, kind):
    b.setdefault('stamps', []).append([kind, time.time()])


def update(store, name, change):
    """Read-modify-write one batch under the lock; `change(b)` edits the record (new on first use)."""
    if not NAME.match(name):
        raise Usage(f'bad batch name: {name}')
    with store.lock():
        b = store.read(name + '.json') or new_batch(name)
        change(b)
        store.write(name + '.json', b)


def cmd_set(store, name, args):
    kv = pairs(args, FIELDS)

    def change(b):
        before = b.get('status')
        b.update({k: int(v) if k == 'pr' else v for k, v in kv.items()})
        st = b.get('status')
        if 'status' in kv:
            if st == 'passed' and 'reviewed_sha' not in kv:
                raise Fail('status=passed needs reviewed_sha=<sha> in the same call')
            if st == 'released' and not same_sha(b.get('released_sha'), b.get('reviewed_sha')):
                raise Fail(f"status=released needs released_sha equal to reviewed_sha ({b.get('reviewed_sha') or 'unset'})")
            if st == 'parked' and not b.get('reason'):
                raise Fail('status=parked needs reason=<reason>')
            if st != before and st == 'passed':
                stamp(b, 'passed')
            if st != before and st in ('released', 'parked'):
                stamp(b, 'ended')
        if b.get('reason') and st != 'parked':
            raise Fail('reason=<reason> goes with status=parked only')
    update(store, name, change)


def cmd_note(store, name, field, path):
    if field not in TEXTS:
        raise Usage(f'note takes one of {", ".join(TEXTS)}')
    try:
        with open(path, encoding='utf-8') as f:
            lines = [l.rstrip() for l in f.read().splitlines() if l.strip()]
    except OSError as e:
        raise Fail(f'cannot read {path}: {e.strerror}')
    update(store, name, lambda b: b.__setitem__(field, lines))


def cmd_bump(store, name, field):
    if field not in COUNTERS:
        raise Usage(f'bump takes one of {", ".join(COUNTERS)}')
    update(store, name, lambda b: b.__setitem__(field, int(b.get(field, 0)) + 1))


def cmd_stamp(store, name, kind):
    if kind not in STAMPS:
        raise Usage(f'stamp takes one of {", ".join(STAMPS)}')

    def change(b):
        stamp(b, kind)
        if kind == 'comment_sent':
            b['status'] = 'review'
            b.pop('reviewed_sha', None)
    update(store, name, change)


def cmd_task(store, name, args):
    if args[:1] == ['add'] and len(args) == 3 and args[1] in KINDS and TASK_ID.match(args[2]):
        def change(b):
            tasks = b.setdefault('tasks', [])
            if not any(t['id'] == args[2] and t['kind'] == args[1] and t['live'] for t in tasks):
                tasks.append({'kind': args[1], 'id': args[2], 'added': time.time(), 'verdict': False, 'live': True})
    elif len(args) == 2 and args[0] in ('verdict', 'done'):
        def change(b):
            hits = [t for t in b.get('tasks', []) if t['id'] == args[1]]
            if not hits:
                raise Fail(f'no task {args[1]} in {name}')
            if args[0] == 'verdict':
                hits[-1]['verdict'] = True
            else:
                for t in hits:
                    t['live'] = False
    else:
        raise Usage(f'task takes `add <{"|".join(KINDS)}> <id>`, `verdict <id>` or `done <id>`')
    update(store, name, change)


def fallthrough_ok(v):
    return all(re.match(r'^[A-Za-z0-9_-]+:(' + '|'.join(WHYS) + r')$', x) for x in v.split(','))


ROUND = {'r': lambda v: INT.match(v) and v != '0', 'sha': SHA.match, 'entry': INT.match,
         'fallthrough': fallthrough_ok, 'explore': lambda v: v in ('pass', 'revise', 'none'),
         'crit': INT.match, 'imp': INT.match, 'minor': INT.match}


def cmd_add_round(store, name, args):
    kv = pairs(args, ROUND)
    missing = [k for k in ROUND if k != 'fallthrough' and k not in kv]
    if missing:
        raise Fail('add-round needs ' + ', '.join(f'{k}=' for k in missing))
    r = {k: int(v) if k in ('r', 'entry', 'crit', 'imp', 'minor') else v for k, v in kv.items() if k != 'fallthrough'}
    r['fallthrough'] = kv['fallthrough'].split(',') if 'fallthrough' in kv else []
    update(store, name, lambda b: b.setdefault('rounds', []).append(r))


def worker_time(b, now):
    """Seconds the worker spent in the spec phase: each `spec_ready` or `stopped` minus the `sent` before it, plus
    now minus an open `sent`; an interval opened by `comment_sent` doesn't count, and `ended` closes any."""
    total, opened = 0.0, None
    for kind, t in b.get('stamps', []):
        if kind == 'sent':
            opened = t
        elif kind == 'comment_sent':
            opened = None
        elif kind in ('spec_ready', 'stopped', 'ended'):
            if opened is not None:
                total += t - opened
            opened = None
    if opened is not None:
        total += now - opened
    return int(total)


def settings(store):
    """spec_phase_timeout, in minutes, from the repo's own config (never FOREMAN_CONFIG, like the hooks)."""
    conf = cfg.load(store.main, use_env=False)
    return int(conf.get('spec_phase_timeout') or cfg.DEFAULTS['spec_phase_timeout'])


def computed(b, timeout, now):
    wt = worker_time(b, now)
    return dict(b, worker_time=wt, remaining=max(0, timeout * 60 - wt))


def cmd_show(store, args):
    as_json = '--json' in args
    names = [a for a in args if a != '--json']
    if len(names) > 1:
        raise Usage('show takes at most one batch')
    if names:
        b = store.read(names[0] + '.json') if NAME.match(names[0]) else None
        if b is None:
            raise Fail(f'no batch {names[0]} in session {store.sid}')
        out = computed(b, settings(store), time.time())
        if as_json:
            print(json.dumps(out, indent=1, sort_keys=True))
        else:
            for k in sorted(out):
                print(f'{k}: {json.dumps(out[k]) if isinstance(out[k], (list, dict)) else out[k]}')
        return
    conf, now = settings(store), time.time()
    out = [computed(b, conf, now) for b in store.batches()]
    if as_json:
        print(json.dumps(out, indent=1, sort_keys=True))
    else:
        for b in out:
            live = ' '.join(f"{t['kind']}:{t['id']}" for t in b.get('tasks', []) if t.get('live'))
            print(f"{b['batch']}  {b.get('status') or 'spec'}  rounds {len(b.get('rounds') or [])}  "
                  f"remaining {b['remaining'] // 60}m  live tasks: {live or 'none'}")


# ---- CLI ---------------------------------------------------------------------------------------------------------

def run(argv):
    args = list(argv)
    given = None
    if '--session' in args:
        i = args.index('--session')
        if i + 1 >= len(args):
            raise Usage('--session needs an id')
        given = args[i + 1]
        del args[i:i + 2]
    if not args:
        raise Usage('no command')
    cmd, rest = args[0], args[1:]
    if cmd not in ('set', 'note', 'bump', 'stamp', 'task', 'add-round', 'show'):
        raise Usage(f'unknown command: {cmd}')
    if cmd != 'show' and not rest:
        raise Usage(f'{cmd} needs a batch')
    store = open_store(given)
    if cmd == 'show':
        return cmd_show(store, rest)
    name, more = rest[0], rest[1:]
    if not NAME.match(name):
        raise Usage(f'bad batch name: {name}')
    if cmd == 'set':
        return cmd_set(store, name, more)
    if cmd == 'add-round':
        return cmd_add_round(store, name, more)
    if cmd == 'task':
        return cmd_task(store, name, more)
    if len(more) != (2 if cmd == 'note' else 1):
        raise Usage(f'{cmd} takes {"a field and a file" if cmd == "note" else "one argument"}')
    return {'note': cmd_note, 'bump': cmd_bump, 'stamp': cmd_stamp}[cmd](store, name, *more)


def main(argv):
    try:
        run(argv[1:])
    except Usage as e:
        print(f'batches.py: {e}\n\n{__doc__}', file=sys.stderr)
        return 2
    except Fail as e:
        print(f'batches.py: {e}', file=sys.stderr)
        return 1
    return 0


if __name__ == '__main__':
    sys.exit(main(sys.argv))
````

````python
def reverse_lines(f, block=1 << 16):
    """The lines of a binary file, last first, read in blocks from its end."""
    f.seek(0, os.SEEK_END)
    pos, rest = f.tell(), b''
    while pos > 0:
        n = min(block, pos)
        pos -= n
        f.seek(pos)
        parts = (f.read(n) + rest).split(b'\n')
        rest = parts[0]
        yield from reversed(parts[1:])

def assistant_lines(path, since):
    """The whitespace-free lines of the assistant text blocks a transcript holds from `since` (epoch seconds, floored
    to the second like the transcript's ISO timestamps) on. Read from the end, it stops at the first entry older than
    `since`, so a long run's transcript costs only its tail. Raises OSError when the transcript can't be read."""
    if not path:
        raise OSError('no transcript_path')
    since, out = int(since), set()
    with open(path, 'rb') as f:
        for raw in reverse_lines(f):
            try:
                e = json.loads(raw)
            except ValueError:
                continue
            if not isinstance(e, dict):
                continue
            t = iso_time(e['timestamp']) if isinstance(e.get('timestamp'), str) else None
            if t is not None and t < since:
                break
            msg = e.get('message')
            if e.get('type') != 'assistant' or not isinstance(msg, dict) or not isinstance(msg.get('content'), list):
                continue
            for b in msg['content']:
                if isinstance(b, dict) and b.get('type') == 'text' and isinstance(b.get('text'), str):
                    out.update(squash(line) for line in b['text'].splitlines())
    return out


def pasted(text, path, at):
    """True when every line of `text` is a line of the assistant's own text written since `at`, whitespace ignored.
    A tool result doesn't count: the human sees only the assistant's text."""
    have = assistant_lines(path, at)
    return all(squash(line) in have for line in text.splitlines() if squash(line))


def table_problem(h, store, name, text, cmd, where):
    """None when the stamp `name` holds `text` and its lines were pasted after it, else the deny reason. An unreadable
    transcript fails open."""
    shown = store.read(name)
    if not isinstance(shown, dict):
        return f'run `{cmd}` and paste its output as text {where}'
    if shown.get('text') != text:
        return f'the table changed since it was shown; run `{cmd}` again and paste its output as text {where}'
    try:
        if pasted(text, h.inp.get('transcript_path'), float(shown.get('at', 0))):
            return None
    except OSError as e:
        print(f'foreman: batch_state could not read the transcript ({e}), so the table check is skipped', file=sys.stderr)
        return None
    return (f"paste the output of `{cmd}` as text {where}: a tool result doesn't count, because the human sees only "
            'your text')


def escaped(repo, store, name, tid):
    """The way out of a deny loop: after two denies against one unchanged table (id `tid`), the third call passes."""
    seen = store.read(name)
    count = int(seen.get('count', 0)) if isinstance(seen, dict) and seen.get('id') == tid else 0
    if count >= 2:
        print(f'foreman: batch_state let this call through after {count} denies against the same table',
              file=sys.stderr)
        return True
    state.write_json(store.path(repo.dirs[0], name), {'id': tid, 'count': count + 1})
    return False
````

````js
// batch from scripts/batches.py (status, and for a batch with a PR its CI, bots, unresolved threads and merge state),
// or, with no batch files, one line per worker worktree (<main>/.claude/worktrees/*). The harness prefixes the

const FAIL = new Set(['FAILURE', 'CANCELLED', 'TIMED_OUT', 'ACTION_REQUIRED', 'STARTUP_FAILURE', 'ERROR'])

export function parseWorktrees(porcelain) {
  const out = []
  for (const line of porcelain.split('\n')) {
    if (line.startsWith('worktree ')) out.push({ path: line.slice(9), branch: null })
    else if (line.startsWith('branch ') && out.length) out[out.length - 1].branch = line.slice(7).replace(/^refs\/heads\//, '')
  }
  return out
}

export function ciCell(checks, required) {
  const state = (c) => {
    const v = (c.conclusion || c.state || '').toUpperCase()
    return PASS.has(v) ? 'pass' : FAIL.has(v) ? 'fail' : 'pending'
  }
  const named = (c) => c.name || c.context || ''
  const relevant = required.length ? required.map((n) => checks.find((c) => named(c) === n) || {}) : checks
  if (!relevant.length) return '—'
  const s = relevant.map(state)
  const fail = s.filter((x) => x === 'fail').length
  const pending = s.filter((x) => x === 'pending').length
  return fail ? `✗${fail}` : pending ? `…${pending}` : '✓'
}

export function toRow(worker, extra, required, bots) {
  const pr = worker.pr
  const seen = bots.filter((b) => (extra?.authors || []).some((a) => a === b || a === `${b}[bot]`)).length
  return {
    name: worker.name,
    pr: pr ? `#${pr.number}` : '—',
    state: pr ? String(pr.state).toLowerCase() : 'no PR',
    sha: pr ? String(pr.headRefOid || '').slice(0, 9) : '',
    ci: pr ? ciCell(pr.statusCheckRollup || [], required) : '—',
    bots: bots.length ? `${seen}/${bots.length}` : '—',
    threads: extra ? extra.threads : 0,
    merge: pr ? String(pr.mergeStateStatus || '').toLowerCase() : '',
  }
}

export function formatRows(list) {
  const cells = list.map((r) => [r.name, r.pr, r.state, r.sha, `ci ${r.ci}`, `bots ${r.bots}`, `threads ${r.threads}`, r.merge])
  const widths = cells[0] ? cells[0].map((_, i) => Math.max(...cells.map((c) => String(c[i]).length))) : []
  return cells.map((c) => c.map((v, i) => String(v).padEnd(widths[i])).join('  ').trimEnd())
}

export function summary(list) {
  const prs = list.filter((r) => r.pr !== '—').length
  const green = list.filter((r) => r.ci === '✓' && r.merge === 'clean').length
  return `${list.length} worker${list.length === 1 ? '' : 's'} · ${prs} PR${prs === 1 ? '' : 's'} · ${green} green`
}

export function unavailable(err) {
  return `status unavailable: ${err?.message || err}`
}

export function batchStatus(b) {
  const done = (b.rounds || []).length
  if (b.status === 'review') return `review r${done + 1}`
  if (b.status === 'passed') return `passed r${done}`
  if (b.status === 'pr') return `PR #${b.pr}`
  return b.status || 'spec'
}

export function batchRow(b, pr, extra, required, bots) {
  return { ...toRow({ name: b.batch, pr }, extra, required, bots), status: batchStatus(b), kind: b.status || 'spec' }
}

export function formatBatchRows(list) {
  const wName = Math.max(0, ...list.map((r) => r.name.length))
  const wStatus = Math.max(0, ...list.map((r) => r.status.length))
  return list.map((r) => {
    const cells = [r.name.padEnd(wName), r.status.padEnd(wStatus)]
    if (r.kind === 'pr') cells.push(r.sha, `ci ${r.ci}`, `bots ${r.bots}`, `threads ${r.threads}`, r.merge)
    return cells.join('  ').trimEnd()
  })
}

export function batchSummary(list) {
  const n = (kind) => list.filter((r) => r.kind === kind).length
  const green = list.filter((r) => r.kind === 'pr' && r.ci === '✓' && r.merge === 'clean').length
  const parts = [`${list.length} batch${list.length === 1 ? '' : 'es'}`]
  for (const [count, label] of [[n('spec'), 'spec'], [n('review'), 'in review'], [n('passed'), 'passed'],
    [n('released'), 'released'], [n('pr'), n('pr') === 1 ? 'PR' : 'PRs'], [n('parked'), 'parked'], [green, 'green']]) {
    if (count) parts.push(`${count} ${label}`)
  }
  return parts.join(' · ')
}

async function threads($, main, numbers) {
  const repo = JSON.parse(await sh($, ['gh', 'repo', 'view', '--json', 'owner,name'], main))
  const fields = 'reviewThreads(first:100){nodes{isResolved}} reviews(last:50){nodes{author{login}}} comments(last:50){nodes{author{login}}}'
  const q = `query($owner:String!,$name:String!){repository(owner:$owner,name:$name){${numbers.map((n) => `p${n}:pullRequest(number:${n}){${fields}}`).join(' ')}}}`
  const data = JSON.parse(await sh($, ['gh', 'api', 'graphql', '-f', `query=${q}`, '-F', `owner=${repo.owner.login}`, '-F', `name=${repo.name}`], main))
  const out = {}

    const logins = [...(p.reviews?.nodes || []), ...(p.comments?.nodes || [])].map((x) => x.author?.login).filter(Boolean)

export async function collect($) {

  const sid = await $.session.id()
  const sd = (await sh($, ['python3', `${$.plugin.root}/scripts/state.py`, cwd], cwd)).trim()
  if (!sd) return null
  const marker = `${sd}/runs/${sid}.json`
  if (!(await $.fs.exists(marker))) return null
  const m = JSON.parse(await $.fs.read(marker))
  if (Date.now() / 1000 - Number(m.touched || 0) > RUN_TTL_S) return null
  const wts = parseWorktrees(await sh($, ['git', 'worktree', 'list', '--porcelain'], cwd))
  const main = wts[0]?.path
  if (!main) return null
  if ((await cfgList($, main, 'status_pane'))[0] === 'false') return null
  if ((await cfgList($, main, 'hooks_disabled')).includes('status_pane')) return null
  const required = await cfgList($, main, 'required_ci')
  const bots = await cfgList($, main, 'review_bots')

  } catch {
    list = null // no batch state (or batches.py failed): the worktree scan below
  }

    const prs = {}
    for (const b of list.filter((x) => x.pr)) {
      prs[b.pr] = JSON.parse(await sh($, ['gh', 'pr', 'view', String(b.pr), '--json', 'number,state,headRefOid,mergeStateStatus,statusCheckRollup'], main))
    }
    const numbers = Object.keys(prs).map(Number)
    const extra = numbers.length ? await threads($, main, numbers) : {}
    return { kind: 'batches', rows: list.map((b) => batchRow(b, b.pr ? prs[b.pr] : null, b.pr ? extra[b.pr] : null, required, bots)) }
  }
  const workers = []
  for (const w of wts.filter((x) => x.path.startsWith(`${main}/.claude/worktrees/`))) {
    const prs = w.branch
      ? JSON.parse(await sh($, ['gh', 'pr', 'list', '--head', w.branch, '--state', 'all', '--json', 'number,state,headRefOid,mergeStateStatus,statusCheckRollup'], main))

  }

  return { kind: 'workers', rows: workers.map((w) => toRow(w, w.pr ? extra[w.pr.number] : null, required, bots)) }
}
````
